02

觀念講解

程式不只會從上往下執行，還能根據條件是否成立決定要走哪一條路。這就是條件判斷。

if 表示「如果條件成立」；else if 表示「否則，如果另一個條件成立」；else 則處理其餘情況。

if / else適合判斷區間、比較大小或組合條件。
switch適合依據同一個值，選擇固定的分支。
條件式常用的比較運算子有 >=（大於或等於）、<=（小於或等於）、==（是否相等）。注意：= 是指定值，不是判斷相等。
03

程式碼範例

範例 A：使用 if / else 判斷成績

建立 Console App，將下列內容放入 Program.cs。由於成績是 82，程式會執行第二個條件分支。

Program.cs · if / else
using System;

class Program
{
    static void Main()
    {
        int score = 82;

        if (score >= 90)
        {
            Console.WriteLine("表現優秀");
        }
        else if (score >= 60)
        {
            Console.WriteLine("成績及格");
        }
        else
        {
            Console.WriteLine("再接再厲");
        }
    }
}

範例 B：使用 switch 判斷星期

以下是另一份獨立的主控台程式，請替換原本的 Program.cs 內容執行。

Program.cs · switch
using System;

class Program
{
    static void Main()
    {
        int day = 2;

        switch (day)
        {
            case 1:
                Console.WriteLine("星期一");
                break;
            case 2:
                Console.WriteLine("星期二");
                break;
            default:
                Console.WriteLine("其他日期");
                break;
        }
    }
}

在 switch 中，case 定義不同選項；break 會結束該分支；沒有符合的選項時會執行 default。

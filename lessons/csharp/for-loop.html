for 迴圈

讓程式自動重複執行指定次數，寫出第一個 for 迴圈。

01

學習目標

完成這個單元後，你將能夠：

  • 說明 for 迴圈的「初始設定、繼續條件、每次更新」三個部分。
  • 使用 for 重複執行一段程式碼。
  • 修改迴圈的起點與終點，判斷程式會執行幾次。
02

觀念講解

如果要把「開始練習」顯示五次，不必寫五行相同的指令。for 迴圈適合用在「大致知道要重複幾次」的情境。

基本寫法是 for（初始設定；繼續條件；每次更新），在 C# 程式碼裡要使用半形括號與分號。

部分範例用途
初始設定int i = 1建立計數變數，從 1 開始；只執行一次。
繼續條件i <= 5每一輪開始前檢查；為 true 才執行迴圈內容。
每次更新i++每完成一輪就把 i 加 1。

執行順序是：設定初始值 → 檢查條件 → 執行大括號內的程式 → 更新變數 → 再次檢查條件。當 i 變成 6 時，i <= 5 不成立，迴圈就會結束。

如果還不熟悉變數和比較運算子，可以先閱讀 變數與資料型態、條件判斷。

03

程式碼範例

在 Visual Studio 建立 Console App（主控台應用程式），將以下完整範例放入 Program.cs。程式會依序印出五次練習訊息。

Program.cs
using System;

class Program
{
    static void Main()
    {
        // 從 1 開始，執行到 5 為止
        for (int i = 1; i <= 5; i++)
        {
            Console.WriteLine($"第 {i} 次練習");
        }
    }
}
1

int i = 1：宣告計數變數，從 1 開始。

2

i <= 5：只要 i 還小於或等於 5，就繼續執行。

3

i++：每完成一輪，把 i 加上 1。

4

$"第 {i} 次練習"：把目前的 i 數值插入顯示文字中。

04

執行結果

按照上面的程式碼執行後，主控台預期會顯示：

Console · 預期輸出
第 1 次練習
第 2 次練習
第 3 次練習
第 4 次練習
第 5 次練習

總共輸出 5 行。記住：i <= 5 包含 5；若改成 i < 5，就只會執行 4 次。

05

練習題目

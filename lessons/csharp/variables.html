變數與資料型態

先學會儲存資料，再讓程式使用這些資訊。

01

學習目標

完成這個單元後，你將能夠：

  • 理解什麼是變數，以及變數用來儲存什麼。
  • 分辨 int、double、string 與 bool。
  • 自行宣告變數，並以 Console.WriteLine() 輸出結果。
02

觀念講解

你可以把變數（Variable）想像成有名稱的盒子：程式會把資料放進盒子裡，之後就能透過名稱取出或修改它。

在 C# 中，宣告變數時需要先指定資料型態，讓程式知道盒子裡要放哪種資料。

資料型態用途範例
int整數85
double小數172.5
string文字"小明"
bool是／否的邏輯值true 或 false
C# 的 string 使用雙引號包住文字；bool 則只有 true 或 false 兩種值。
03

程式碼範例

開啟 Visual Studio，建立 Console App（主控台應用程式），將以下程式放入 Program.cs。這裡使用一般的 Main() 寫法，便於認識程式的入口。

Program.cs
using System;

class Program
{
    static void Main()
    {
        string studentName = "小明";
        int score = 85;
        double height = 172.5;
        bool isPassed = score >= 60;

        Console.WriteLine($"姓名：{studentName}");
        Console.WriteLine($"成績：{score}");
        Console.WriteLine($"身高：{height} 公分");
        Console.WriteLine($"及格：{isPassed}");
    }
}
1

string studentName = "小明"; 宣告文字變數，並指定初始值。

2

int score = 85; 宣告整數變數，存放成績。

3

bool isPassed = score >= 60; 使用比較運算，得到邏輯值。

4

$"...{score}" 是字串插值語法，可以把變數放入輸出文字中。

04

執行結果

執行程式後，主控台預期會顯示：

主控台輸出
姓名：小明
成績：85
身高：172.5 公分
及格：True

注意：C# 在預設情況下輸出布林值時會顯示 True 或 False（首字母大寫）。小數的顯示格式可能受系統地區設定影響。

05

練習題目

TRY IT YOURSELF

製作自己的個人資料卡

請修改範例程式，建立姓名、年齡、身高與是否為學生四個變數，並使用 Console.WriteLine() 將資料輸出。

完成條件
  • 至少使用三種不同的資料型態。
  • 輸出內容與變數儲存的值一致。

Button 按鈕事件

從表單設計到事件處理，完成第一個可以互動的視窗程式。

建議先閱讀：變數與資料型態

01

學習目標

完成這個單元後，你將能夠：

  • 在 Visual Studio 建立 Windows Forms 專案。
  • 在設計工具中加入 Button 和 Label 控制項。
  • 使用 Click 事件，讓按鈕被點擊時更新文字。
02

觀念講解

Windows Forms 是用來建立 Windows 桌面視窗程式的 UI 技術。你可以透過 Visual Studio 的設計工具放置按鈕與文字，再以 C# 處理使用者操作。

Button可供使用者按下的按鈕控制項。
Label用來在表單上顯示文字。
Click當使用者點擊按鈕時發生的事件。
事件處理方法指定事件發生後要執行的程式碼。
Windows Forms 是 Windows 桌面應用程式技術，需在支援的 Windows 開發環境中實際執行；這個教學網站只是提供操作步驟與程式碼，不會在網頁裡執行 Windows Forms。
03

程式碼範例

步驟一：建立與設定表單

在 Windows 的 Visual Studio 中建立 Windows Forms App（C#） 專案；此範例以支援 Windows Forms 的 .NET 專案為例。假設專案命名為 FirstWinFormsApp，使用預設表單 Form1。

  1. 在設計工具中，將一個 Button 和一個 Label 拖曳到表單上。
  2. 在屬性視窗中把 Button 的 (Name) 設成 btnGreet、Text 設成「點我打招呼」。
  3. 將 Label 的 (Name) 設成 lblMessage、Text 設成「尚未點擊」。

步驟二：撰寫事件處理程式

開啟 Form1.cs 的程式碼檢視，將類別調整為以下範例。請保留設計工具自動產生的 Form1.Designer.cs，因為控制項是在設計工具裡建立的。

Form1.cs
using System;
using System.Windows.Forms;

namespace FirstWinFormsApp
{
    public partial class Form1 : Form
    {
        public Form1()
        {
            InitializeComponent();
            btnGreet.Click += BtnGreet_Click;
        }

        private void BtnGreet_Click(object sender, EventArgs e)
        {
            lblMessage.Text = "你好，Windows Forms！";
        }
    }
}

這段程式在建構子中以 btnGreet.Click += BtnGreet_Click; 訂閱按鈕事件；之後點擊按鈕，便會執行對應方法，更新 lblMessage.Text。

若你先前已在 Visual Studio 設計工具的事件清單設定 Click 事件，請勿再重複用 += 訂閱同一個事件，以免處理方法執行兩次。
04

執行結果

按 F5 啟動 Windows Forms 程式。初始狀態顯示「尚未點擊」；按下「點我打招呼」按鈕後，Label 的文字會更新：

05

練習題目

TRY IT YOURSELF

為表單新增第二個按鈕

新增名為 btnReset 的按鈕，文字設為「重設」，點擊後讓 lblMessage 恢復顯示「尚未點擊」。

完成條件
  • 兩個按鈕有不同的 (Name)。
  • 打招呼與重設能各自更新 Label。
  • 事件沒有重複訂閱。
